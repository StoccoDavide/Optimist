Detailed Description

template<typename Vector, Integer N>
class Optimist::TestSet::Ackley< Vector, N >

\[ f(\mathbf{x}) = -20\exp\left(-0.2\sqrt{\frac{1}{N}\sum x_i^2}\right) - \exp\left(\frac{1}{N}\sum\cos(2\pi x_i)\right) + 20 + e \text{,} \]

a nearly flat outer region riddled with local minima around a deep funnel with global minimum \( f(\mathbf{0}) = 0 \). The usual search domain is \( [-5, 5]^N \). It is meant for global optimizers. The Hessian is obtained by forward-mode automatic differentiation of the gradient (Eigen's AutoDiffScalar). The function is not differentiable at the origin, where the gradient is set to zero.
