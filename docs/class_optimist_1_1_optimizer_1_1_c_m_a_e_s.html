Detailed Description

template<typename Vector>
requires TypeTrait<Vector>::IsEigen && (!TypeTrait<Vector>::IsFixed || TypeTrait<Vector>::Dimension > 0)
class Optimist::Optimizer::CMAES< Vector >

Covariance matrix adaptation evolution strategy

The CMAES class implements the \((\mu/\mu_w, \lambda)\)-CMA-ES following Hansen's tutorial (2016). At each generation \(\lambda\) points are sampled from \(\mathcal{N}(\mathbf{m}, \sigma^2\mathbf{C})\), and the best \(\mu = \lambda/2\) are recombined with logarithmic weights to update the mean \(\mathbf{m}\). The covariance \(\mathbf{C}\) learns the local shape of the cost function through a rank-one update (along the evolution path \(\mathbf{p}_c\)) and a rank- \(\mu\) update, while the step size \(\sigma\) is adapted by cumulative step-size adaptation (path \(\mathbf{p}_\sigma\)). The method is invariant to rotations and monotone transformations of the cost and handles ill-conditioned and multimodal problems well.

A run stops when \(\sigma\max_i\sqrt{\lambda_i(\mathbf{C})}\) falls below the tolerance. With restarts(k) the solver performs up to \(k\) IPOP restarts, doubling the population at each restart and starting from a random point of the bounded box, and returns the best point found. Samples outside finite bounds are projected onto the box.
