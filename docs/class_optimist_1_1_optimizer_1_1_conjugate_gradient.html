Detailed Description

template<typename Vector>
requires TypeTrait<Vector>::IsEigen && (!TypeTrait<Vector>::IsFixed || TypeTrait<Vector>::Dimension > 0)
class Optimist::Optimizer::ConjugateGradient< Vector >

Conjugate gradient methods

The ConjugateGradient class implements the nonlinear conjugate gradient iteration

\[ \mathbf{x}_{k+1} = \mathbf{x}_k + \alpha_k \mathbf{d}_k, \qquad \mathbf{d}_{k+1} = -\mathbf{g}_{k+1} + \beta_k \mathbf{d}_k \text{,} \]

where \(\mathbf{g}_k = \nabla f(\mathbf{x}_k)^\top\).

The update parameter \(\beta_k\) can be selected among the standard formulas summarized in Table 1.1 of Hager and Zhang's survey:

  • Hestenes-Stiefel
  • Fletcher-Reeves
  • Polak-Ribiere
  • Polak-Ribiere+
  • Conjugate Descent
  • Liu-Storey
  • Dai-Yuan
  • Hager-Zhang
  • Hager-Zhang+

The implementation uses the line searches of Optimist::LineSearch (strong Wolfe by default, or Moré-Thuente, Armijo and Goldstein), retries along the steepest descent direction when the conjugate direction fails, and supports a Powell-style restart safeguard whenever the conjugate direction loses reliability. The Hager-Zhang+ variant applies the standard survey-style truncation bound controlled by the solver truncation parameter.

The initial trial step passed to the line search can also be selected. By default the solver reuses the last accepted step. An optional Barzilai-Borwein alpha update computes

\[ \alpha_{k+1}^{BB} = \frac{\boldsymbol{s}_k^T \boldsymbol{s}_k}{\boldsymbol{s}_k^T \boldsymbol{y}_k} ext{,} \]

with \(\boldsymbol{s}_k = \mathbf{x}_{k+1} - \mathbf{x}_k\) and \(\boldsymbol{y}_k = \mathbf{g}_{k+1} - \mathbf{g}_k\), and falls back to the last accepted step when the curvature estimate is not positive or becomes numerically unreliable.

> Reference: Hager W. W., Zhang H., A Survey of Nonlinear Conjugate Gradient Methods, Pacific Journal of Optimization, 2 (2006), pp. 35-58.

Compute \( \beta_k \) with the selected formula. Degenerate denominators are detected relative to the scale of the vectors involved, so that the formulas keep working when the gradient is small (i.e., close to the minimizer); in that case \( \beta_k = 0 \) (steepest descent).
