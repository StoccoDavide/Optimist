class Optimist::RootFinder::LevenbergMarquardt< Vector, OutVector >

Levenberg-Marquardt method

The LevenbergMarquardt class solves \(\mathbf{f}(\mathbf{x}) = \mathbf{0}\) by minimizing \(\frac{1}{2}\|\mathbf{f}\|^2\) with the damped Gauss-Newton step

\[ (\mathbf{J}^\top\mathbf{J} + \lambda\mathbf{D})\,\mathbf{h} = -\mathbf{J}^\top\mathbf{f} \text{,} \]

where \(\mathbf{D} = \mathrm{diag}(\mathbf{J}^\top\mathbf{J})\) (Marquardt's scaling, default) or \(\mathbf{D} = \mathbf{I}\). The damping interpolates between Gauss-Newton ( \(\lambda \to 0\)) and scaled steepest descent (large \(\lambda\)), and is updated with Nielsen's rule from the ratio between actual and predicted reduction: \(\lambda \leftarrow \lambda\max(1/3, 1-(2\rho-1)^3)\) on success, \(\lambda \leftarrow \nu\lambda\), \(\nu \leftarrow 2\nu\) on failure.

The damped normal equations remain solvable when the Jacobian is singular, which makes the method more robust than Newton's method far from the solution and at singular roots (where the convergence becomes linear). The solver also accepts overdetermined systems of \(m > n\) equations, LevenbergMarquardt<Input, Output>: the iteration then stops either at a root or at a least-squares solution, where \(\|\mathbf{J}^\top\mathbf{f}\| < \epsilon\max(1, \|\mathbf{f}\|)\).

Template Parameters
VectorEigen vector type of the unknowns.
OutVectorEigen vector type of the equations (by default the system is square). With more equations than unknowns the system is solved in the least-squares sense.
