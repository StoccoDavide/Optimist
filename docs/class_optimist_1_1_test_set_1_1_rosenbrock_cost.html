Detailed Description

template<typename Vector, Integer N>
requires (N >= 2)
class Optimist::TestSet::RosenbrockCost< Vector, N >

\[ f(\mathbf{x}) = \sum_{i=1}^{N-1} 100(x_{i+1} - x_i^2)^2 + (1 - x_i)^2 \text{,} \]

with global minimum \( f(1, \dots, 1) = 0 \) at the end of a long, narrow, curved valley. Unlike Rosenbrock, which exposes the residuals of the decoupled variant to root finders, this is the scalar cost function used to benchmark optimizers.
