Detailed Description

Line searches

Descent optimizers update the iterate as \(\mathbf{x}_{k+1} = \mathbf{x}_k + \alpha_k \mathbf{d}_k\), where \(\mathbf{d}_k\) is a descent direction, \(\nabla f(\mathbf{x}_k)^\top \mathbf{d}_k < 0\). The step \(\alpha_k\) is chosen by a line search on \(\phi(\alpha) = f(\mathbf{x}_k + \alpha\mathbf{d}_k)\). Four strategies are available in the Optimist::LineSearch namespace:

  • Armijo backtracking enforces the sufficient decrease condition

    \[ \phi(\alpha) \leq \phi(0) + c_1 \alpha \phi'(0) \text{,} \]

    shrinking the trial step by safeguarded quadratic interpolation. It needs function values only.
  • Goldstein enforces \(\phi(0) + (1-c)\alpha\phi'(0) \leq \phi(\alpha) \leq \phi(0) + c\alpha\phi'(0)\) with \(0 < c < 1/2\), by expansion and bisection, which also rules out steps that are too short.
  • Strong Wolfe enforces sufficient decrease together with the curvature condition \(|\phi'(\alpha)| \leq c_2|\phi'(0)|\) (Nocedal and Wright, Algorithms 3.5 and 3.6), with a bracketing phase followed by a zoom phase based on safeguarded cubic interpolation. It guarantees \(\mathbf{s}_k^\top\mathbf{y}_k > 0\), which keeps quasi-Newton updates positive definite, and it is the default choice of the BFGS solver.
  • Moré-Thuente (1994) enforces the same strong Wolfe conditions with the safeguarded cubic and quadratic interpolation steps of MINPACK-2 (dcsrch/dcstep), working on the auxiliary function \(\psi(\alpha) = \phi(\alpha) - \phi(0) - c_1\alpha\phi'(0)\) until a suitable bracket is found.

Close to a minimizer the decrease of \(\phi\) falls below its rounding error, so that a literal sufficient decrease test would reject every step. All searches therefore accept \(\phi(\alpha) \leq \phi(0) + c_1\alpha\phi'(0) + \epsilon_f|\phi(0)|\), and compare function values inside the bracket only above that level (below it, the derivative decides), in the spirit of the approximate Wolfe conditions of Hager and Zhang. The default \(\epsilon_f = 100\,\epsilon\) can be raised for cost functions evaluated with heavy cancellation.

The parameters ( \(c_1 = 10^{-4}\), \(c_2 = 0.9\), \(c = 0.25\), \(\epsilon_f\), maximum step and number of trials) are collected in LineSearch::Settings.

All line searches work on the restriction of the objective to the search direction, \( \phi(\alpha) = f(\mathbf{x} + \alpha\mathbf{d}) \), and are therefore independent of the vector type. The restriction is provided as a callable with signature

bool phi(Scalar alpha, Scalar &value, Scalar *derivative);

where derivative is nullptr when \( \phi'(\alpha) \) is not needed.
