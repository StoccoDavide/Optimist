class Optimist::Optimizer::BFGS< Vector >

BFGS and L-BFGS methods

The BFGS class implements the Broyden-Fletcher-Goldfarb-Shanno quasi-Newton method, where the search direction \(\mathbf{d}_k = -\mathbf{H}_k \nabla f(\mathbf{x}_k)\) uses an approximation \(\mathbf{H}_k\) of the inverse Hessian, updated with the step \(\mathbf{s}_k = \mathbf{x}_{k+1} - \mathbf{x}_k\) and the gradient change \(\mathbf{y}_k = \nabla f(\mathbf{x}_{k+1}) - \nabla f(\mathbf{x}_k)\) as

\[ \mathbf{H}_{k+1} = (\mathbf{I} - \rho_k \mathbf{s}_k \mathbf{y}_k^\top) \mathbf{H}_k (\mathbf{I} - \rho_k \mathbf{y}_k \mathbf{s}_k^\top) + \rho_k \mathbf{s}_k \mathbf{s}_k^\top \text{,} \qquad \rho_k = \frac{1}{\mathbf{y}_k^\top \mathbf{s}_k} \text{.} \]

The initial approximation is rescaled after the first step by \(\mathbf{s}^\top\mathbf{y}/\mathbf{y}^\top\mathbf{y}\), and the update is skipped whenever the curvature condition \(\mathbf{s}_k^\top\mathbf{y}_k > 0\) fails.

The limited-memory variant (Method::LBFGS) stores only the last \(m\) pairs \((\mathbf{s}_i, \mathbf{y}_i)\) and computes \(\mathbf{H}_k\nabla f\) with the two-loop recursion, so that memory and cost per iteration are \(O(mn)\).

The step is selected by one of the line searches of Optimist::LineSearch (strong Wolfe by default), whose sufficient decrease condition tolerates changes of the cost below its rounding error, so that the iteration can proceed until \(\|\nabla f\| < \epsilon\) even when \(|f|\) is large at the minimizer.
