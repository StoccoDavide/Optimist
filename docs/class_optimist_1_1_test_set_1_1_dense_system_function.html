Detailed Description

template<typename Vector, Integer N, typename Derived, typename OutVector = Vector, Integer M = N>
requires TypeTrait<Vector>::IsEigen && TypeTrait<OutVector>::IsEigen && (!TypeTrait<Vector>::IsFixed || TypeTrait<Vector>::Dimension == N) && (!TypeTrait<OutVector>::IsFixed || TypeTrait<OutVector>::Dimension == M)
class Optimist::TestSet::DenseSystemFunction< Vector, N, Derived, OutVector, M >

The derived class implements

  • void residual(const Dense &x, Dense &F) const,
  • void jacobian(const Dense &x, DenseMatrix &J) const,
  • void hessian(const Dense &x, Integer i, DenseMatrix &H) const, the Hessian of the \( i \)-th component.
