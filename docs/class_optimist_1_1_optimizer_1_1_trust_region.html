Detailed Description

template<typename Vector>
requires TypeTrait<Vector>::IsEigen && (!TypeTrait<Vector>::IsFixed || TypeTrait<Vector>::Dimension > 0)
class Optimist::Optimizer::TrustRegion< Vector >

Trust-region Newton method

The TrustRegion class minimizes the quadratic model

\[ m_k(\mathbf{p}) = f(\mathbf{x}_k) + \nabla f(\mathbf{x}_k)^\top\mathbf{p} + \frac{1}{2}\mathbf{p}^\top\nabla^2 f(\mathbf{x}_k)\mathbf{p} \quad \text{subject to} \quad \|\mathbf{p}\| \leq \Delta_k \text{,} \]

and accepts the step if the ratio between the actual and the predicted reduction, \(\rho_k\), is positive enough. The radius is reduced when \(\rho_k < 1/4\) and enlarged when \(\rho_k > 3/4\) and the step reached the boundary. Unlike line-search Newton methods, the iteration is well defined when the Hessian is indefinite.

Two subproblem solvers are available:

  • Steihaug-Toint truncated conjugate gradient (default), which stops at the boundary of the region or along a direction of negative curvature, and only needs Hessian-vector products;
  • Powell's dogleg, which moves along the piecewise-linear path from the Cauchy point to the Newton point, and falls back to Steihaug-Toint when the Hessian is not positive definite.

For vector-valued functions the solver minimizes \(\frac{1}{2}\|\mathbf{f}\|^2\) with the full Hessian \(\mathbf{J}^\top\mathbf{J} + \sum_i f_i\nabla^2 f_i\).
