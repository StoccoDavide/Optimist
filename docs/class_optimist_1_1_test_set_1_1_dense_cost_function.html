Detailed Description

template<typename Vector, Integer N, typename Derived>
requires TypeTrait<Vector>::IsEigen && (!TypeTrait<Vector>::IsFixed || TypeTrait<Vector>::Dimension == N)
class Optimist::TestSet::DenseCostFunction< Vector, N, Derived >

The derived class implements

  • Scalar value(const Dense &x) const,
  • void gradient(const Dense &x, Dense &g) const,
  • void hessian(const Dense &x, DenseMatrix &H) const,

and this class takes care of the conversion from/to fixed-size, dynamic-size and sparse Eigen vectors.
