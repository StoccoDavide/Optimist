Detailed Description

template<typename Vector>
requires TypeTrait<Vector>::IsEigen && (!TypeTrait<Vector>::IsFixed || TypeTrait<Vector>::Dimension > 0)
class Optimist::Optimizer::NelderMead< Vector >

Nelder-Mead method

The NelderMead class implements the downhill simplex method in the form of Lagarias et al. (1998). A simplex of \(n+1\) points is moved by reflection ( \(\rho\)), expansion ( \(\chi\)), outside and inside contraction ( \(\gamma\)) and shrinking ( \(\sigma\)), using function values only.

  • The initial simplex is either axis-aligned around the initial guess (STANDARD, choosing the best of \(\pm\delta\) on each axis) or regular (SPENDLEY).
  • When the simplex degenerates, i.e., its volume normalized by that of a regular simplex with the same diameter falls below a tolerance, it is rebuilt around the best point.
  • The adaptive coefficients of Gao and Han (2012), \(\rho = 1\), \(\chi = 1 + 2/n\), \(\gamma = 3/4 - 1/(2n)\), \(\sigma = 1 - 1/n\), can be enabled with adaptive_mode(true) to improve the behaviour in higher dimension.

The iteration stops when both the spread of the function values and the simplex diameter are below the tolerance. The simplex is stored densely, so that fixed-size, dynamic-size and sparse vectors are all supported.
